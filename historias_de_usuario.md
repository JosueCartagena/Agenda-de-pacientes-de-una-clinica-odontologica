\# NOMBRE PROYECTO

Agenda de pacientes de una clínica odontológica

\## Introducción

Nostros somos una clínico odontológica que ofrecemos los mejores servicios para tus

dientes donde tenemos implementado una aplicación para poder agendar citas

con nuestros odontólogos desde casa y un perfil para tener recordatorios sobre cuando

nuestros dientes :D

\### Descripción general del sistema

Desarrollar un sistema donde se puede tener un control de citas con los odontólogos

y poder agendar dichas citas también tener recordatorio a los pacientes de cuando es la cita.

\### Objetivo General

Como objetivo general es el de ofrecer una aplicación para poder agendar citas

con los odontólogos y de esta manera tener todo mas ordenado

\### Objetivos específicos

RELLENAR

- Poder agendar la cita con los dentista
- Tener un sencillo manejo de la aplicación
- Hacer notificaciones para que el paciente se acuerde cuando es su cita
- Tener la capacidad de poder cambiar o cancelar de cita con el dentista
- Tener la funcionalidad las notificaciones de funcionar sin estar conectado a internet
- Adaptabilidad para todos los dispositivos móviles

\## HISTORIAS DE USUARIO OBJETIVO ESPECÍFICO 1

RELLENAR

HU-01: Como paciente nuevo, debo poder seleccionar una fecha y hora disponible para el odontólogo, para no tener que llamar a la clínico de odontología.

Criterio de Aceptación: El sistema muestra las fechas y horas disponibles en tiempo real al paciente.

Si no hay horarios disponibles en el rango de búsqueda, el sistema no muestra un mensaje claro o sugiere alternativas.

\## HISTORIAS DE USUARIO OBJETIVO ESPECÍFICO 2

HU-02:Como odontólogo quiero ver todas mis citas de una semana de todos los pacientes que tendré, para tener listo todos los materiales para mis pacientes.

Criterio de Aceptación: El odontólogo puede ver una vista semanal de todas sus citas programadas, incluyendo la información esencial del paciente.

Si hay una cita cancelada o modificada, el sistema no actualiza la vista semanal del odontólogo de forma inmediata.

\## HISTORIAS DE USUARIO OBJETIVO ESPECÍFICO 3

HU-03:Como paciente quiero, recibir recordatorios de mi citas como odontólogo para poder acordarme y llegar temprano a mi cita con el odontólogo.

Criterio de Aceptación: El paciente recibe un recordatorio automático (ej. SMS o notificación push) con al menos 24 horas de antelación a la cita.

Si el paciente no tiene configurado un método de contacto válido (ej. número de teléfono), el sistema no informa sobre la imposibilidad de enviar recordatorios.

\## HISTORIAS DE USUARIO OBJETIVO ESPECÍFICO 4

HU-04:Como paciente, quiero poder usar la aplicación en mi celular android y que mi madre también lo pueda usar en su iPhone, para que no tenga necesitar mi celular.

Criterio de Aceptación: La aplicación es funcional y compatible con dispositivos Android e iOS, ofreciendo la misma experiencia de usuario en ambas plataformas.

Si la aplicación se instala en un dispositivo con una versión de sistema operativo antigua, no se muestra un mensaje de compatibilidad o la aplicación funciona de forma errática.

\## HISTORIAS DE USUARIO OBJETIVO ESPECÍFICO 5

HU-05:Como odontólogo, quiero poder cancelar mi cita por si tengo un imprevisto, para que mi paciente no venga en vano.

Criterio de Aceptación: El odontólogo puede cancelar una cita desde su interfaz y el sistema notifica automáticamente al paciente sobre la cancelación.

Si el odontólogo intenta cancelar una cita con muy poca antelación (ej. 30 minutos antes), el sistema no permite la cancelación y no ofrece una alternativa para informar al paciente.

\## HISTORIAS DE USUARIO OBJETIVO ESPECÍFICO 6

HU-06:Como paciente senil, quiero tener una sencilla interfaz en la aplicación, para poder usar la aplicación sin problemas.

Criterio de Aceptación: La interfaz de usuario presenta botones grandes, texto legible, y una navegación intuitiva y simplificada, minimizando la cantidad de pasos para realizar una acción clave.

Si un elemento interactivo (botón, campo de texto) no tiene una etiqueta clara o un contraste de color adecuado, dificultando su uso para personas con discapacidad visual.
